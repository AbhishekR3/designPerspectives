# Specification

The specification and the implementation plan are kept in the owner's claude.ai project
"System Architecture Visualization Tool", not in this repository:

- `designPerspectives/designPerspectives-spec-v0.2-bundle.md` — vision, the tool's own architecture, perspectives, design process, file format, diagram catalog, LLM integration, technology reviews, testing strategy, ADRs, wave files.
- `designPerspectives/implementation-plan-v0.2.md` — owner decisions, agent roles, task breakdown per wave.

They are not copied here because they cite page numbers and summaries of two books (*The C4 Model*, *Fundamentals of Software Architecture*); the owner decides whether that material belongs in a public repository. Code comments cite spec sections as `spec file NN §N` and book pages as `[C4 p.N]` / `[FoSA p.N]`.
